# Feedback and contributions

Questions, ideas, and conversation are welcome in [Discussions](https://github.com/richardkaufmann/converse/discussions). For something broken, use the [bug-report form](https://github.com/richardkaufmann/converse/issues/new/choose).

Please remove credentials, account emails, private file paths, and private conversation contents from public reports, logs, and screenshots.

Pull requests are by invitation. Only repository collaborators can open them. You're welcome to fork the project and change it for your own use; discuss proposed upstream changes before working on a contribution.

Invited collaborators have write access. Work on a branch and open a PR against `main`. The repository owner reviews changes before merging. `main` requires a code-owner approval, dismisses approvals when changes are pushed, and blocks force pushes and deletion. The owner retains administrative bypass for maintenance.
